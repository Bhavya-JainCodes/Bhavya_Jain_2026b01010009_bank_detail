# Bank Data Cleaning Project
This project cleans raw banking data (`bank.csv`) and generates a clean, analysis-ready dataset (`bank_cleaned.csv`) using Python.
The `project.py` script was built in VS Code using `pandas` and `numpy` to handle missing values, duplicates, and data formatting.
To run the project locally, install `pandas` and `numpy` and execute `python project.py` in your terminal.
